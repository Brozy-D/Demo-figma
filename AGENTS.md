## Commit Guidelines

Every commit must be a conventional commit. please follow the conventional commit guidelines when making changes to this repository. This ensures that our commit history is clear and consistent, making it easier to understand the purpose of each change.

- feat: Introduce new feature or enhancement
- fix: Address a bug or issue
- docs: Update documentation or comments
- style: Code formatting, white-space, or other non-functional changes
- refactor: Code changes that neither fix a bug nor add a feature
- test: Add or update tests 


## Security Guidelines

When contributing to this repository, please adhere to the following security guidelines:

- Avoid committing sensitive information such as passwords, API keys, or personal data.
